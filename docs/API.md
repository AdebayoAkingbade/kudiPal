# KudiPal API Surface

The live OpenAPI contract is generated by Springdoc at `/v3/api-docs`.

Primary endpoint groups:

- `POST /api/webhook/whatsapp`: Meta WhatsApp Cloud API inbound messages.
- `GET /api/webhook/whatsapp`: Meta webhook verification.
- `POST /api/webhook/paystack`: Paystack payment events with HMAC validation.
- `GET /api/marketplace/ops/dataset`: JSONL export for prompt evaluation.
- `POST /api/marketplace/ops/prompts/rollover`: Create a new prompt version.

Expected DTO practices:

- All public request bodies should use DTOs, not entities.
- DTO fields should use Jakarta validation annotations.
- Money is represented in minor-free naira integer amounts unless explicitly integrating with Paystack, where amount is converted to kobo.
- AI responses must be parsed as structured JSON and rejected if the intent schema is invalid.
